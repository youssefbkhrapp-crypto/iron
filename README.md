# IPTVFlixPro — Premium IPTV Website

A modern, premium IPTV website built with Next.js 14, Tailwind CSS, and Framer Motion.

## Setup Instructions

### 1. Install Node.js
Download and install Node.js (v18 or higher) from: https://nodejs.org

### 2. Install dependencies
Open a terminal in this folder and run:
```
npm install
```

### 3. Start development server
```
npm run dev
```
Open http://localhost:3000 in your browser.

### 4. Build for production
```
npm run build
npm start
```

## Pages
- `/` — Home page with hero, features, devices, pricing, testimonials, FAQ

- `/faq` — Full FAQ with search
